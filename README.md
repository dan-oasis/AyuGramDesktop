# mTelegram

mTelegram is an unofficial desktop client based on Telegram Desktop 7.3.5.

Download the Windows x64 Debug package from the **Artifacts** section of a successful [Windows build](../../actions). Extract the whole archive and launch `mTelegram.exe`.

See [build instructions](docs) and the original authors’ [license](LICENSE) and [notices](LEGAL).
