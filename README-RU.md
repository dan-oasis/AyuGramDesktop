# mTelegram

mTelegram — неофициальный клиент на основе Telegram Desktop 7.3.5.

Скачайте ZIP для Windows x64 Debug в разделе **Artifacts** успешной [сборки Windows](../../actions). Распакуйте архив целиком и запустите `mTelegram.exe`.
